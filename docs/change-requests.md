# 変更要求の記録

範囲外の機能・改善や、計画の変更は、実装せずにここへ記録する（CLAUDE.md 11.2）。
判断は発注者が行い、承認されたものだけを実装する。記録する前に `change-request-reviewer` で内容を確認する。
フェーズ2（③ レビュー支援、④ 日次機能）に当たるものは、件名に「フェーズ2候補」と付ける。

## 書式

```markdown
### CR-NNN 件名
| 項目 | 内容 |
| --- | --- |
| 記録日 | YYYY-MM-DD |
| 内容 | 何をどう変えるか |
| きっかけ | 実際に起きた出来事 |
| 範囲内か外か | 範囲内／範囲外／フェーズ2候補（CLAUDE.md 4章に照らして） |
| 工数と日程への影響の見込み | 軽／中／重と、根拠 |
| 寄与する目的 | 目的（CLAUDE.md 1.2）・ゴールの状態（G1〜G7）のどれか、または「なし」 |
| 判断 | 未判断／承認／却下（判断日・判断者） |
```
