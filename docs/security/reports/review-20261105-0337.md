## 指摘一覧

### SEC-001　Low　E（ブラウザの保存）・F（CI）
- **該当箇所**：`src/buildInfo.ts:9`、`src/domain/persistence.ts:16-20`、`.github/workflows/pr-preview.yml` のビルドのステップ
- **根拠**：プレビューを本番と別の名前空間にするかどうかは、CIが渡す `VITE_PR_PREVIEW` だけで決まり、値が無ければ本番の名前空間になる。ワークフローがこの値を渡していることを確かめるテストが無かった
- **影響**：ワークフローの変更でこの値が抜けると、マージ前のコードが本番の保存データを読み書き・消去しうる（今は正しく渡しているので、退行したときだけの問題）
- **修正案**：ワークフローが値を渡していることをテストで確かめる。任意で、URLに `/pr-preview/` があるのに PR の番号が無ければ保存を止める（今回は見送り。テストで退行を防げるため）
- **対応するテスト**：`security/repo-hygiene.security.test.ts`「pr-preview.yml：ビルドに PR の番号（VITE_PR_PREVIEW）とプレビューの配信先（BASE_PATH）を渡し、本番と別の名前空間で保存させる」。値を消すと失敗することを確かめた

### SEC-002　Low　F（依存関係）
- **該当箇所**：`package-lock.json`（minimatch 10.2.6。eslint・typescript-eslint の依存）
- **根拠**：`npm audit` で moderate が10件（GHSA-g3hv-75wg-m249。globパターンによるDoS）。`npm audit --omit=dev` は0件
- **影響**：開発用の依存（lint）だけ。パターンはリポジトリの設定から来るので、悪用の経路は実質無い。本番の成果物には入らない
- **修正案**：修正版が出たら Dependabot のPRで取り込む。`npm audit fix --force`（eslint の版の下げ戻し）はしない
- **対応するテスト**：テストできない（外部の依存の状態のため）

### SEC-003　Info　B（CSP）
- **該当箇所**：`vite.config.ts:4-14`
- **根拠**：metaタグでは `frame-ancestors` が効かず、GitHub Pages ではヘッダーを付けられない。受け入れの記録が CLAUDE.md・チェックリストに無い
- **影響**：別のサイトの枠の中に読み込まれうるが、主要なブラウザは別のサイトの枠の中の localStorage を分けて保存するので、実データには届かない。読み込みにはファイルを選ぶ操作が要る
- **修正案**：受け入れるリスクとして記録する（発注者に判断を求める）

### SEC-004　Info　C（入力と表示）
- **該当箇所**：`src/domain/text.ts:15`
- **根拠**：拒否する制御文字は C0・DEL・C1 だけで、文字の向きを変える制御文字（U+202E など）や幅の無い文字は通る
- **影響**：表示はすべて React のテキストなので XSS は起きない。見た目を偽れるだけで、読み込むのは自分が書き出したJSONのため、影響はごく小さい
- **修正案**：必要になったら向きの制御文字を拒否する。今は対応しない

## 問題の無かった項目

- **A 実データ・秘密情報**：どのブランチの履歴にも、実データのJSON・CSV・env は無い（架空のテスト用の fixture 1件と設定ファイルだけ）。トークン・鍵の形の文字列は0件。`.gitignore` は `tmpoc-*`・`.env*`・`exports/`・`backup/` を除外し、テストで確かめている
- **B 外部通信**：src に fetch・XHR・WebSocket・sendBeacon・外部URLは無く、ESLint で禁じ、その禁止をテストで確かめている。本番のCSP（`connect-src 'none'` など）はテストがある。`index.html` は `no-referrer`
- **C 入力の検証**：検証は許可リストで項目を絞り、型を確かめた値だけで組み立て直す。`__proto__` などの危険なキーはどの階層でも拒否し、入れ子の深さ・件数・文字数・状態全体600万字・ファイル32MiB に上限がある。1つでも誤りがあれば何も取り込まない。`dangerouslySetInnerHTML` と入力値の `href` は無い
- **D 完全性**：reducer で状態を外から置けるのは、検証し直す読み込みと消去だけ。読み込みと消去には確認がある
- **E 保存**：localStorage に触るのは `persistence.ts` だけ（ESLint で強制）。読めないデータでは自動保存を止めて上書きしない。別のタブの変更で読み取り専用にする。消去はこの名前空間だけ。端末名は許可リストで16字まで
- **F CI**：lint・型・テスト・`npm audit --omit=dev`・gitleaks・ビルド・`check-dist.sh` を実行。トップレベルは `contents: read`、書き込みは配信のジョブだけで、そのジョブはコマンドを実行しない。checkout は `persist-credentials: false`、Action は sha で固定、`pull_request_target` は使わない。本番の依存は react・react-dom だけ
- **人手で確認する項目**：Pages の配信元、`main` のルール（リポジトリの設定のため、未確認）
