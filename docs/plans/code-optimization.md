## 4. 今回は見送るもの

| 内容 | 見送る理由 |
| --- | --- |
| React 19・TypeScript 7 へのメジャー更新 | 利点が少なく、壊れる危険がある。TypeScript 7 は typescript-eslint が未対応で、lint（安全対策の一部）が動かなくなる。Dependabot の設定でも提案させないと決めている（`.github/dependabot.yml`） |
| TypeScript の `noUncheckedIndexedAccess`（配列の要素が無いかもしれないことを型で扱わせる） | 違反145件のうち142件がテストの中で、テストを大きく書き換えることになり、差分のレビューが重い。アプリのコードの3件は、どれも直前に長さを確かめていて不具合ではない |
| 画面の自動テスト（ブラウザを動かすテスト）と、テストの網羅率の計測 | 新しい依存と CI が要る（AGENTS.md 7章で、理由を示して承認を得たときだけ足すと決めている）。画面は今のとおり PR プレビューで確かめる。必要なら 12/27 の年次設計セッションの議題にする |
| `App.tsx` の `eslint-disable` 1か所（退避の有無を、起動時と消去のときにだけ読む工夫） | 意図して書いたもので、理由のコメントもある。外すと、描画のたびに大きな値を読むことになる |
