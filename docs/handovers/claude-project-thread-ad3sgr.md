## 2. 設計上の決定事項・前提

- **画面（CSS 中心）だけの変更**。フォーカスを移す動き（`focus()`）、知らせを読み上げに伝える `role="status"` の要素（常に置いて中身だけを変える）は変えていない
- **計画・改善提案から変えたこと**（自己点検の指摘による。洋平さんの確認待ち）
  1. **重ねて出すのは、3秒で消える成功の知らせ（「収集箱に入れました」）だけにした**（改善提案 4.2 は知らせの行を丸ごと重ねる案）。使えない理由・500字を超えた誤り・入れられなかった誤りは消えないので、重ねると下の受け渡しの状態の行を隠し続けてしまう。これらは出ているあいだだけ流れの中に出す。重ねる知らせは `--info-bg` の色で区切る（改善提案の `--surface` と影ではなく）
  2. **スマホの薄い文字を「思いつきを入力」にした**（改善提案 4.3 は「思いついたことを入力」）。幅360pxで、改善提案の文言でも切れたため
  3. **下部タブの5つの列を同じ幅にした**（`minmax(0, 1fr)`。改善提案 4.1 には無い）。文字の長いタブだけ広がってアイコンの間隔がずれないように。字間を詰めるのは文字だけ（件数の数字は詰めない）。幅380px以下では文字を少し小さく、300px以下（端末の文字サイズを大きくしたとき）では折り返す
  4. **枠を出さない見出しに `scroll-margin-top` を付けた**。フォーカスした見出しが上部の固定部分の下に隠れないように
  5. **読めなかった保存データのときの案内の向きを直した**（「上の帯の操作で直すと」→「下の帯の操作で直すと」。`src/App.tsx`）。帯は画面の下に出るため。改善提案には無い、ついでの直し
