## 1. 週次レビュー（毎週土曜）

既存の週次レポートに合わせて、土曜に行います。画面の切替の並びは、この順に合わせてあります。ツールは「何をすべきか」を判定しないので、件数と一覧を自分の目で見て直します（CLAUDE.md 4.3）。

| 順 | 画面 | すること |
| --- | --- | --- |
| ① | 収集箱 | ［明確化を始める］で、1件ずつ振り分けて収集箱を空にする。決められないものは「いつか・多分」へ |
| ② | 次のアクション | 終わったものを完了にする。もう要らないものは削除する。別の置き場が合うものは［編集］→［移す…］ |
| ③ | 連絡待ち | 返事が来たものを完了にする。催促が要るものは、次のアクションを足す |
| ④ | プロジェクト | 一覧の「次のアクション N件・連絡待ち M件」を目で見る。0件で進めたいものは、詳細で次の一手を足す。終わったものは［完了にする］（未完了の次のアクション・連絡待ちも一緒に完了になる） |
| ⑤ | いつか・多分 | 始めたいものを［移す…］でプロジェクトや次のアクションへ。もう要らないものは削除する |
| ⑥ | 年次目標・四半期シート、ロードマップ | 今の四半期の重点テーマと主要プロジェクトを見直す。来期に回すものは、ロードマップでカードを移す（PCはドラッグ、スマホはカードの ⋯） |
| ⑦ | 共通の画面の［書き出す］ | JSONを書き出して、バックアップとして保存する（3章） |

- 収集箱を空にした回数と週次レビューの回数はツールに残らないので、1週間の運用（G7）の間は、手元のメモ（リポジトリの外）に1日1行で書き、振り返り（`docs/retrospective.md`）の日別の表に書き写します。メモの列と書き方は `docs/plans/milestone-4.md` 2.5 にあります。タスクやプロジェクトの内容は書きません
- 操作を間違えたら、画面の下の［元に戻す］で直前の1つを戻せます（明確化・完了・削除・移動・四半期の移動）

### 1.1 四半期・年度が変わった最初の週次レビュー

ツールは、四半期や年度が変わっても何も知らせず、何も自動では動かしません（CLAUDE.md 4.3）。変わった後の最初の週次レビューの⑥で、次も行います。月次の見直しはツールの外の月次レポートで行い、ツールの中では扱いません（CLAUDE.md 4.2）。

- **新しい四半期のシートは空から始まる**：重点テーマ・やらないことは、前の四半期から引き継がれません。年次目標・四半期シートの画面で、新しい四半期の重点テーマ（最大3つ）とやらないことを書きます。主要プロジェクトは、その四半期に置いたプロジェクトです
- **前の四半期に置いたまま進行中のプロジェクトは、そのまま前の四半期に残る**：続けるものは、ロードマップで新しい四半期へ移します（終わらせる予定の四半期に置く。CLAUDE.md 5.1）
- **年度が変わったとき（4月）**：年次目標・四半期シートとロードマップは、新しい年度で開きます。新しい年度の年次目標は空なので、テーマごとに到達状態を書きます。前の年度に置いたまま進行中のプロジェクトは、ロードマップの表の下の「前の年度までに置いた、進行中のプロジェクト」に並ぶので、続けるものは新しい年度の四半期へ移します
- **年次目標を見直すタイミング**：四半期が変わった最初の週次レビュー（年に4回）に、その年度の年次目標を読み直し、到達状態の書き方が今と合わなくなったものを直します。年度が変わるときは上のとおり書き直します

## 2. PCとスマホの間の受け渡し

データはブラウザごとに別々で、自動では同期しません。JSONの書き出しと読み込みで、手で受け渡します。**読み込みは置き換え**なので、両方の端末で並行して変更すると、読み込んだ側の変更は失われます。

### 2.1 最初に1回だけ

1. 受け渡し用に、個人のクラウドストレージ（例：Googleドライブ）に専用のフォルダを作る
2. そのフォルダの共有の設定を開き、**自分のほかに誰もいない**ことを確かめる（リンクの共有も「制限付き」にする）
3. 各端末で、⋯ →［このブラウザの名前を変える］で短い名前を付ける（例：「PC」「スマホ」）。書き出すファイル名と、読み込みの確認画面に出ます

### 2.2 使う端末を替えるたびに

1. **使い終わった端末**で、共通の画面の［書き出す］を押す
   - PC：ダウンロードしたファイルを、受け渡し用のフォルダへ移す
   - スマホ（Android）：ファイルは「ダウンロード」フォルダに保存されるので、ファイルのアプリの共有から「ドライブ」へ送り、受け渡し用のフォルダを選ぶ
2. **次に使う端末**で、⋯ →［JSONを読み込む］→ 受け渡し用のフォルダからそのファイルを選ぶ
3. 確認画面で、書き出し元の端末名と日時が、さっき書き出したものかを見る。「最後に書き出した後に、このブラウザで変更があります」と出ていたら、この端末の変更は置き換えで消えるので、残したいときは先に［今のデータを書き出す］を押す
4. ［置き換える］を押す
5. 受け渡し用のフォルダから、読み込んだファイルと、それより古いファイルを消す

- 共通の画面の「最後に書き出した」「最後に読み込んだ」は、この手順を支えるための表示です。今どちらの端末のデータが新しいかを確かめるときに見ます
- ファイル名は `tmpoc-<端末名>-<日時>.json` です。私的な内容そのものなので、受け渡し用のフォルダとバックアップの保存先のほかには置きません

## 3. バックアップ

- 週次レビューの最後（⑦）に書き出したJSONを、**このリポジトリのフォルダの外**の、自分のPCのフォルダに保存する（リポジトリは公開されているため。CLAUDE.md 8.3）。`.gitignore` は `tmpoc-*` を除外していますが、それに頼らず、リポジトリの外に置きます
- 古いバックアップを消すかどうかは自由です。戻したいときは、その日のファイルを［JSONを読み込む］で読み込みます

### 3.1 端末をなくしたとき

データはブラウザの中にしかなく、サーバーにも控えはありません。なくした端末のデータは取り出せないので、**最後に書き出したJSON（受け渡し用のフォルダ・バックアップ）と、もう一方の端末のデータが、残っている控えのすべて**です。最後に書き出した後に、なくした端末で変えた分は戻りません。

1. もう一方の端末（または新しい端末）で、共通の画面の「最後に書き出した」「最後に読み込んだ」の日時と、受け渡し用のフォルダ・バックアップのファイル名の日時を見比べ、いちばん新しいものを決める
2. いちばん新しいのがファイルなら、［JSONを読み込む］で読み込む（新しい端末なら、先に 2.1 の3で名前を付ける）
3. なくした端末のブラウザには、私的なデータが残っています。このツールには遠くから消す機能が無いので、端末そのものの機能（Androidの「デバイスを探す」など）で、端末をロックするか消去します

## 4. PRプレビューと保存データの消し方

PRごとのプレビュー（`.../pr-preview/pr-<番号>/`）は、マージ前のコードの確認用です（CLAUDE.md 8.3、セキュリティレビュー①の SEC-005）。

- **プレビューには実データを入れない**。画面の上に「プレビュー：実際のデータを入れないでください」の帯が出ます。確かめるときは、PRに書いてある架空のデータ（例：`src/domain/__fixtures__/roadmap-demo.json`）を読み込みます
- プレビューの保存データは本番と別の場所（名前空間）にあり、本番の［このブラウザの保存データを消去］では消えません。確かめ終わったら、**そのプレビューを開いたまま** ⋯ →［このブラウザの保存データを消去］で消します（消えるのは、そのプレビューの分だけ）
- PRを閉じた後のプレビューは開けなくなるので、残った保存データはブラウザの設定から消すしかありません。ただし、ブラウザの「サイトのデータを消す」は `yoheitaniguchi.github.io` の全部（本番のこのツールと、同じ場所のほかのアプリ）を消します。行うときは、**先に本番で［書き出す］**を押してから消し、消した後に本番でそのファイルを読み込みます。同じ場所のほかのアプリ（`project_management_poc` など）にデータがあれば、それも先に書き出しておきます
  - PCのChrome：アドレスバーの左のアイコン →［サイトの設定］→［データを削除］
  - AndroidのChrome：アドレスバーの左のアイコン →［権限］または［サイトの設定］→［データを削除］
- 残ったプレビューの保存データは、同じ場所の保存の容量を少しずつ使うだけで、本番のデータには触れません。急いで消す必要はありません

## 5. 困ったとき

| 起きたこと | すること |
| --- | --- |
| 画面の上に「このブラウザに保存できませんでした」の帯が出た | すぐに［書き出す］でJSONを保存する。容量が足りないときは、資料の本文やメモの長いものを減らす |
| 「別のタブで変更されました。このタブは読み取り専用です」と出た | 別のタブで同じツールを開いて変更した。帯の［再読み込み］を押すか、このタブを閉じて新しい方のタブを使う |
| 起動したら「保存データを読めませんでした」と出た | 帯の［読めなかったデータを書き出す］で書き出してから、［JSONを読み込む］で最後のバックアップを読み込む |
| 読み込もうとしたら理由が出て読み込めなかった | 今のデータは変わっていない。別のファイル（1つ前のバックアップなど）を選ぶ |
