## 指摘一覧

### SEC-007　Info　E（ブラウザの保存）・A
- **該当箇所**：`docs/weekly-review.md` 4章（PRプレビューの保存データの消し方）
- **根拠**：閉じたPRのプレビューの保存データを消す手順として、ブラウザの「サイトのデータを消す」を案内している。この操作が同じ場所（オリジン）全体を消すことは書いていたが、先に書き出すよう促していたのはこのツールだけだった
- **影響**：同じ場所の姉妹PoC（`project_management_poc`）の保存データも消える。手順は任意（「急いで消す必要はありません」）で、このツールのデータは書き出しで守られるため、影響は小さい
- **修正案**：「同じ場所のほかのアプリにデータがあれば、それも先に書き出しておく」と一文足す
- **対応**：PR 10 で直した（手順書に一文を足した）
- **対応するテスト**：無し（文書の指摘。Info なので `/security-review` の手順でもテストの対象外）

### PR 9 の点検で受け入れたもの（記録）
- Chromium 系のブラウザでは、カードのドラッグに入れる独自の種類（`application/x-tmpoc-project`）の値が、別のタブのページにも渡りうる。入れるのはプロジェクトの id（UUID）だけで、名称などの内容は入れないため、Info として受け入れる

## 該当なしとした項目と理由

- **A 公開リポジトリと実データ**：追加したデータファイルは `src/domain/__fixtures__/roadmap-demo.json` だけで、決められた置き場にある。中身はすべて「架空の〜」で、読み込むのはテストだけ。ビルド成果物にも含まれない（成果物は index.html・CSS・JS・favicon の4つ）。`tsconfig.tsbuildinfo` は差分に無い。手順書の受け渡しの手順は CLAUDE.md 12.3 と一致している（共有しない専用のフォルダ、共有の設定の確認、読み込んだ後に古いファイルを消す、バックアップはリポジトリの外）
- **B 外部通信**：追加したコードに `fetch`・XHR・WebSocket・`window.open`・外部 URL は無い。CSS に `url(`・`@import` は無い。成果物の CSP（`default-src 'self'; connect-src 'none'; object-src 'none'; base-uri 'self'; form-action 'none'`）は変わっていない
- **C 入力と表示**
  - `dangerouslySetInnerHTML` は無い。新しい `href` はどれも `routeHref` を通り、プロジェクトの id は UUID の形のときだけ URL に入る
  - ドラッグ（計画 2.3）：カードが入れるのは独自の種類の id だけ。`droppedProject` はその種類だけを読み、`getData` の例外を捕まえ、64字を超える値を捨て、存在する id だけを受け取る。移す先の年度・四半期・テーマは落としたセルから取る。`placeProject` はテーマが違えば失敗、年度の範囲外・知らない id も失敗にする。`text/plain`・`text/uri-list`・ファイルを無視することを `@security` のテストで確かめている
  - 画面全体での止め方（`App.tsx`）：入力欄の外ではファイル・リンクの既定の動きを止め、入力欄に落としたファイルも止める
- **D データの完全性（5.3）**
  - 新しい操作（14個）はすべて `timed` → `applyResult` → `validateState` を通る。reducer の default は何もしない。知らない出口・知らない置き場の種類・知らない子の扱い・読めない時刻は、どれも例外ではなく失敗を返す（SEC-006 は PR 6 で対応した）
  - 重点テーマは最大3つ（`plan.ts`、検証と同じ定数）。完了したプロジェクトには子を足せない。件数と大きさの上限は `checkCount`・`checkSize` で守る。時計のずれは `stampFor`・`laterOf` で扱う
  - `validate.ts` の変更は定数への置き換えだけで、検証を厳しくしていない。スキーマは v1 のまま。節目2の関数で作ったデータを読めることは `compat.test.ts` で確かめている
  - プロジェクトの削除は確認画面を通す。そのほかの日常の操作は「元に戻す」で救う
- **E ブラウザの保存**：追加したコードで localStorage・sessionStorage・Cookie に触るところは無い。読み取り専用のタブでは、変更の操作（ドラッグ・メニューを含む）を止めている
- **F CI・依存関係**：設定・依存は変わっていない。audit は0件
