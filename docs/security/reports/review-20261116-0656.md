## 指摘一覧

### SEC-008　Info　E（ブラウザの保存）
- **該当箇所**：`src/domain/persistence.ts` の `getStorageManager`・`requestPersistence`、`src/state/usePersistedState.ts`（起動時に1回求める）、`src/components/AppHeader.tsx`（状態の表示）
- **根拠**：`navigator.storage.persist()` の保護は、オリジン `yoheitaniguchi.github.io` 全体にかかる。同じオリジンの姉妹アプリや PR プレビューが先に保護を得ていると、このアプリが求めなくても「あり」と出る
- **影響**：漏えい・改ざんにはつながらない。「あり」が、このアプリの操作で得たものとは限らない、という読み違いが起きうるだけ
- **修正案**：設計に「保護はオリジン全体にかかる」と書く
- **対応**：対応済み。`docs/design.md` 6.1 の「保存の保護」に、オリジン全体にかかること、ほかのアプリや PR プレビューの結果で「あり」と出ること、「あり」が防ぐのは容量不足での自動の消去だけであることを、PR #37 で書いてある。同じオリジンを共有するリスクは、受け入れ済みの範囲（開発指示書 8.2）として扱う
- **対応するテスト**：無し（Info なので `/security-review` の手順でもテストの対象外。保護を求める関数そのものは `@security` のテストで確かめている）

### SEC-009　Info　E（ブラウザの保存）
- **該当箇所**：`eslint.config.js` の保存の禁止の規則（`no-restricted-properties`）
- **根拠**：プロパティの名前で禁じるので、`Reflect.get(navigator, "storage")`、変数をキーにした `navigator[k]`、`window["local" + "Storage"]` では止まらない（`eslint --stdin` で確かめた）。`navigator?.storage?.persist()`、分割代入、`document["cookie"]` は止まる。今の `src/`（テストを除く）に、動的な添字の参照・`Reflect.`・規則を外す `eslint-disable` は無い
- **影響**：わざと避けないと書かない形なので、理論上だけ
- **修正案**：今のまま、レビューで守る。コードで守るなら `no-restricted-syntax` に `Reflect.get` などを足す（lint の設定の変更になるので、洋平さんの承認が要る）
- **対応**：受け入れ（レビューで守る残りのリスク）。`docs/design.md` 6.1 に PR #37 で書いてある。設定は変えない
- **対応するテスト**：無し（Info）。止まる形は `security/eslint-rules.security.test.ts` で規則の id まで確かめている

## 見てほしいとした点の確認結果

- **`navigator.storage` などを `persistence.ts` の外で使えないこと**：問題なし。禁止の一覧に `storage`・`storageBuckets`・`openDatabase`・`cookie`・`cookieStore`・`caches` があり、対象に `.jsx`・`.mjs`・`.cjs` も入っている。除外は `src/domain/persistence.ts` だけ。`getStorageManager` は `persisted`・`persist` の2つだけを包んで返す（`@security` のテストあり）
- **読み込みの確認で、書き出さずに置き換える経路**：意図どおり。ボタンは `importActions`（`transfer.ts`）が決める。変更があって書き出していないときは［今のデータを書き出す］が主ボタンで、［書き出さずに置き換える］も出る。書き出せないとき（読み取り専用、読めなかったデータ、端末名が無い）は理由の文言と［書き出さずに置き換える］だけ。置き換えは検証に通ったデータがあるときだけ押せ、失敗したら状態を変えない。確認画面そのものが取り消せない操作の確認になっている
- **実データ・秘密情報**：見つからなかった。`src/domain/__fixtures__/review-demo.json` は、すべて「架空の〜」の文言・連番の ID で、読むのはテストだけ。引き継ぎ文書・計画・AGENTS.md・`docs/ai/` の追加分に、私的な内容・メールアドレス・金額は無い。コミットのメールアドレスは noreply のものだけ
- **新しい外部通信**：無い。`href` はアプリの中の画面へのリンクだけ。`fetch`・`sendBeacon`・`window.open`・CSS の `url(`・`@import`・`@font-face` は無い
- **CSP**：変わっていない（SEC-003 の行）
- **`validateState`**：厳しくも緩くもなっていない（`validate.ts`・`types.ts`・`reducer.ts` はこの範囲で変わっていない）。`firstNextAction`・`quarterShortLabel` は表示のための読み取りだけ。テーマのボタンの値は決まった選択肢からしか来ない
- **`useMediaQuery` の購読解除**：正しい。同じ effect の中で `addEventListener` と `removeEventListener` を組にし、条件が変われば付け直す
